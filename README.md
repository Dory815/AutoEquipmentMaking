# 新人装备自动制作

Minecraft Java Edition 26.2 的 Fabric 客户端模组。机器人支持新人礼包和批量工具两种工作模式。机器人读取工坊内的未染色潜影盒与普通箱子，集中采购缺货的附魔书、弓和盾牌，并把成品装入指定颜色的潜影盒。批量模式每盒交付 27 把精准采集镐或 27 件满附魔鞘翅。

## 正式版 1.3.1 使用

依赖 Minecraft 26.2、Fabric Loader 0.19.5、Fabric API 0.158.0+26.2、Java 25 和 MaLiLib 0.29.3。MaLiLib 0.29.3 是当前客户端与 MiniHUD 0.40.4 已验证可共存的最低版本；更早版本未验证。服务端按既有配置使用 Servux 0.11.2，无须安装本模组。

按 `F6` 打开设置。默认快捷键：`F8` 开始、`F10` 暂停、`F12` 恢复、`F9` 急停并保留任务、`Ctrl+F9` 取消旧任务、`B` 绑定交付箱。取消后再次按 `F8` 会重新扫描开工，不恢复旧任务进度。也可输入 `/aem cancel`。开始时，模组提示指向一个工坊范围内的箱子并按 `B`。任意玩家发送 `skip` 时，模组选用已绑定的有效箱子；找不到时选最近的有效箱子。旧任务继续使用 `good` 补货确认，以及聊天中的 `pause` 和 `continue`。

设置界面支持手动套数或自动识别。手动套数范围为 1–10；自动识别范围的长度和宽度均为 3–51，高度为 1–21，默认扫描 `21×21×5`。本模组字体倍率可设为 0.1–3.0，默认 1.0，不改变 Minecraft 或其他模组的文字。高倍率时，文字可能超出界面。产物盒方块 ID 列表默认只有 `minecraft:light_blue_shulker_box`，只接受潜影盒。可关闭迅捷潜行、灵魂疾行、鞘翅、盾牌、村民交易和备用铁砧取出。运行中的任务使用启动时的设置快照；新设置从下次开始生效。工坊坐标保存在 `config/auto-equipment-making/workshop.json`，界面设置保存在同目录的 `settings.json`。

工坊标记命令和故障恢复见 [运行说明](docs/V11_IMPLEMENTATION.md)。

2026-10-25 用户整理后的真实交易所基准保存于 `runtime/test-baselines/201-trading-hall-user-arranged-20261025/world`，含 58 个文件并逐文件校验。场景测试从该基准的独立副本开始。用户移动的刁钻原料位置完整保留；新寻路使用这个场景验收。取样、校验与归档见 [真实场地测试存档](docs/201_TEST_WORLD.md)。

PCL 当前安装 `1.3.1`，用户配置保持原样。1.3 源码沿用 v1.1 的新寻路、自动疾跑与真实跳跃提升。开阔平路疾跑，转弯、窄边和起跳阶段减速；支持按住和切换疾跑选项。新寻路依据玩家碰撞箱和方块形状选择落脚点，包含竖直活板门旁的偏移空间。设置界面、缓存修复和取消重开继续保留。实现和验收状态见 [201 活板门寻路](docs/V11_TRAPDOOR_NAVIGATION.md)。旧实现仍归档于 `client/src/experimentalNavigation/`，不参与编译。历史回退记录见 [1.0.4](docs/V1_ALPHA_NAVIGATION_ROLLBACK.md)。

此前 1.1 寻路开发版在整理后的 201 独立副本中连续交付 3 盒、42 件装备，消耗 957 级。三个产物盒随机分散，实际访问高处原料盒，298 个活板门不变；两种疾跑选项均验证。任务没有报错、暂停或重开。内部重算和游戏日志警告的范围见验收记录；不代表正式服或远程网络通过。

v1.1 开发版按每件装备的优先级使用未附魔下界合金、附魔钻石、未附魔钻石；缺少半成品时才合成钻石装备。附魔钻石先在真实砂轮菜单去除附魔，再升级。材料预算只计当前路线所需数量；完全复用下界合金时不需要合成或锻造材料。沿用满耐久、无改名、无诅咒规则；砂轮不能去除诅咒。工坊内砂轮自动发现，或使用 `/aem mark grind` 标记。缺少砂轮时等待 `good`。见 [半成品功能](docs/V11_PARTIAL_EQUIPMENT.md)。

## 构建与验证

使用 JDK 25、Gradle Wrapper 9.6.1 和项目的 `.gradle-user-home`。将 `JAVA_HOME` 指向 JDK 25，将 `GRADLE_USER_HOME` 指向项目 `.gradle-user-home`，执行 `./gradlew.bat --no-daemon build`，当前版本的成品路径为 `client/build/libs/auto-equipment-making-client-1.3.1.jar`。`client/src/gametest` 中的游戏测试不进入成品 jar。修复与 PCL 同步记录见 [缓存修复](docs/V1_SERVUX_CACHE_MISS.md)、[活板门旁的寻路恢复](docs/V1_TRAPDOOR_RECOVERY.md)和 [取消后重新开工](docs/V1_CANCEL_RESTART.md)。

当前版本与验证范围见 [正式版 1.3.1](docs/release-notes/1.3.1.md)。历史版本见 [发布记录](docs/RELEASES.md)。历史记录见 [Alpha 1.2 单人验证](docs/V11_RC4_SINGLEPLAYER_VALIDATION.md)、[Alpha 1.3 交易优化](docs/V11_TRADE_SPEED.md)和 [Alpha 1.3 边界修复](docs/V11_RC6_EDGE_FIXES.md)。产品范围见 [PRD](docs/PRD.md)，安全执行约束见 [技术标准](docs/TECHNICAL_SPEC.md)。
