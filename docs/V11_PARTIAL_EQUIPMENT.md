# v1.1：优先使用半成品

## 范围

2026-10-25 用户要求保存整理后的真实交易所基准，并开发 v1.1 的第一个功能。半成品从工坊边界内的未染色潜影盒与普通箱子读取；交付箱和染色盒不作为原料。初始背包仍全部保护。本轮用户明确允许使用旧简单单人测试场地，不启动整理后的真实场景或连接 201。

基准归档见 [真实交易所存档](201_TEST_WORLD.md)。该基准的刁钻原料位置保留，寻路未验证。

## 半成品顺序

按目标装备类型，逐件预留以下输入。每件原料只预留一次；两个不同附魔版本的剑或镐分别占用自己的半成品：

1. 未附魔的下界合金装备：直接进入基础装备装箱和附魔，免去钻石合成及下界合金升级。
2. 已附魔的钻石装备：取出后在真实砂轮菜单去除附魔并清零铁砧惩罚，再升级为下界合金。
3. 未附魔的钻石装备：直接升级为下界合金。
4. 没有可用半成品：使用钻石、木棍合成钻石装备，再升级。

沿用现行成品质量域：满耐久、无改名、无诅咒；直接使用的未附魔底材要求铁砧惩罚为 0。附魔钻石允许带已有铁砧惩罚，由砂轮清除。损坏、改名、带诅咒的装备和已附魔下界合金装备不自动消耗。本轮没有增加损坏修复、改名或保留旧附魔功能。

材料预算根据实际路线计算。直接复用下界合金装备不消耗锭或模板；复用钻石装备只消耗升级材料；只为确实新制的底材预取钻石和木棍。完全复用下界合金时，不要求钻石、木棍、升级材料、工作台、锻造台或砂轮。

所有选定半成品在砂轮前集中取出，防止第一把去附魔的钻石镐被错误算作另一把普通钻石镐的来源。之后一次访问砂轮、按需一次访问工作台、按需一次访问锻造台，再沿用基础装备装箱和分批附魔流程。

## 砂轮

自动发现工坊内最近砂轮。也可使用 `/aem mark grind` 记录砂轮，保存到可选的 `workstations.grindstones` 数组；旧配置缺少该字段时仍可自动发现。只有选择了附魔钻石半成品时才要求砂轮。

预检缺砂轮时保留物资并等待 `good`。放置砂轮后仍不自行恢复；收到 `good` 后重新扫描。砂轮步骤使用现有确认式 `Put`、`Click`、`TakeResult` 事务，只接受满耐久、无附魔、无改名、惩罚为 0 的实际菜单输出；确认输入消耗后记录结果，不直接修改物品组件代替操作。未确认点击仍遵守原有暂停与对账规则。

资料核对：[中文 Minecraft Wiki：砂轮](https://zh.minecraft.wiki/w/%E7%A0%82%E8%BD%AE) 和项目本地 Minecraft 26.2 的 `GrindstoneMenu.removeNonCursesFrom` 均表明，砂轮移除非诅咒附魔而保留诅咒。测试另行检查原版菜单对绑定诅咒、消失诅咒的保留行为；正式服附加规则不在本轮验证范围。

## 代码与版本

`BaseEquipmentPlan` 负责按类型预留半成品及动态材料预算。`Grinding` 负责砂轮选点与实际菜单操作。`Robot.prepare` 在规划前使用半成品预算；`ProductionBatches` 只执行所需制作阶段。取消或新任务清除半成品计划；每盒重新扫描并重新选择。

开发版版本号为 `1.1.0-alpha.1`，修订标记 `partial-equipment-20261025`。继续使用 1.0.4 的 Alpha 寻路；本轮不恢复暂存的新导航。游戏测试代码不进入分发 jar。
