# 站立面判断与取消后重新开工

日期：2026-10-24。

## 本次故障

PCL 1.0.2 的最新任务扫描到 3 个空产物盒、62 个原料容器和 1084 个物品堆。规划费用为 344 级。进入首次容器寻路时，报错 `玩家不在安全站立面上`。该任务没有制作或交付装备。

旧日志只记录玩家所在方块 `(1068,57,23)`，没有实际脚部高度和碰撞快照，因此不能确认现场具体是哪一种地面。源码检查发现，导航对脚部高度向上取整确定节点，却又拒绝比节点低超过半格的地面，地毯和底部活板门会被错误拒绝。站在方块边缘时，玩家有真实支撑，但所在方块中心没有支撑，也会触发同一错误。

独立单人存档的 `before-fix` 用地毯复现同一报错，失败证据保留。原用户日志只读归档到本地 `docs/evidence/v1-restart-investigation/task.jsonl`。

## 修复

- 地面高度与玩家节点采用同一归类规则，支持薄地面。
- 如果当前格中心不适合站立，但玩家真实位置安全且有支撑，则选择相邻、可连续走到的安全节点作为路径起点。沿途仍检查碰撞、危险方块和地面支撑。
- 新日志记录实际脚部坐标；起点检查失败时记录节点、地面高度、碰撞和支撑结果。

## 取消旧任务，再重新开始

用户明确选择取消旧任务，再重新扫描开工。此功能不恢复旧任务进度。

默认按 `Ctrl+F9` 取消，或输入 `/aem cancel`。取消会丢弃旧队列，取消待用的规划结果，并清除原任务的扫描、报价、批次、产物盒、补货等待和连接观察状态。现场物资保留，不回滚服务端交易或合成，不自动转移光标物品。

取消后按 `F8`，按提示绑定交付箱；已有有效交付箱时可以让任意玩家发送 `skip`。新任务使用当前设置和新的扫描结果。菜单必须关闭，光标必须为空。新任务按原规则保护背包初始物品；如果要复用上次取出的原料，请先放回原料容器。

`F9` 为急停并保留旧任务，`F10` 暂停，`F12` 恢复可继续的暂停任务。未确认的旧消耗操作仍不能通过恢复直接重发。默认取消快捷键可在 `F6` 设置界面修改；旧配置没有 cancel 字段时使用新默认值，不重置既有选项。
