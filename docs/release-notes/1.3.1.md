# 正式版 1.3.1

Minecraft 26.2 的 Fabric 客户端模组。本次发布整合批量工具、旧装备复用、新寻路，以及矿车村民交易修复。

## 新增功能

- 设置分为「全局设置」「新人装备」「批量工具」。全局设置选择工作模式。
- 批量工具支持 1–10 盒，每盒 27 件同种物品。默认使用黄色潜影盒，可指定其他潜影盒物品 ID。
- 支持精准采集下界合金镐、精准采集钻石镐和满附魔鞘翅。两种镐均通过真实铁砧命名为「挖山镐」。镐附效率 V、精准采集、耐久 III、经验修补；鞘翅附耐久 III、经验修补。
- 新人装备增加「是否使用旧装备制作」。开启后优先复用合格的未附魔下界合金，其次使用经砂轮去附魔的钻石装备、普通钻石装备，最后新制底材。初始背包保护和诅咒限制继续生效。
- 同类报价缺货时继续其他同级候选村民。全部同级候选菜单均售罄后，聊天提示并每 20 秒复查；自然补货后继续原任务。

## 修复与改进

- 矿车村民使用实际实体位置和多个可见身体点作为交互目标，修正脚部方块低于地面导致的“没有安全路线”。实体视线按碰撞形状检查，消除告示牌选取框造成的误判；购买仍确认真实服务端菜单。
- 寻路使用方块碰撞形状、薄面和偏移落脚点，支持真实跳跃提升、自动疾跑及窄边减速。
- 包含此前本地版本的 Servux 缓存缺失修复、初始物品保护与取消旧任务功能。

## 安装与升级

下载 `auto-equipment-making-client-1.3.1.jar`，放入游戏版本的 `mods` 目录，移除旧版同模组 jar。升级前关闭游戏并备份配置，保留 `config/auto-equipment-making/settings.json` 与 `workshop.json`。新增设置在缺失时读取默认值。

依赖：Minecraft 26.2、Java 25、Fabric Loader 0.19.5、Fabric API 0.158.0+26.2、MaLiLib 0.29.3。远程库存与村民报价使用 MiniHUD 0.40.4 和服务端 Servux 0.11.2。

`F6` 设置，`F8` 开始，`F10` 暂停，`F12` 恢复，`F9` 急停保留任务。补货或补经验后，在游戏内发送 `good`。`Ctrl+F9` 或 `/aem cancel` 会清空旧任务队列，仅用于明确放弃任务后重新扫描。任务进度保留在当前进程内，尚不支持关闭游戏后的自动续作。

## 验证范围

- 批量工具单人测试：两种镐各 27 把、各 1 盒；鞘翅连续 54 件、2 盒；关闭旧装备的新人工序 14 件、1 盒。合计 5 盒、122 件，54 次真实命名。轮换和真实 20 秒冷却另有采购用例。
- 1.3.1 定向回归：三个原始矿车村民均打开实际交易菜单；交易轮换与冷却回归通过。10 项引擎测试通过，分发包不含游戏测试。
- 1.3.1 正式服新人装备验收：同一任务交付 2 盒、28 件，实际采购 40 笔，支付 228 颗绿宝石，消耗 570 级。两次自然补货、三次界面暂停及一次补经验后继续原任务，最终队列为空。交付箱原有物品保持。用户随后确认实际测试没有问题。
- 正式服验收使用了旧装备复用；没有在正式服验证批量工具、多名耐久 III 村民轮换、砂轮及新制底材。批量最长 10 盒未运行验收。没有采集服务端 MSPT/TPS，性能警告原因仍未确认。
