# 正式版 1.0

Minecraft 26.2 的 Fabric 客户端模组。读取工坊原料，集中向村民采购缺货，制作和附魔装备，最后装箱交付。

## 本次改动

- MaLiLib 设置界面，支持快捷键、手动套数、扫描范围、产物盒颜色、可选装备和附魔；设置在任务开始时固定。
- 复用原版 A* 搜索和地形分类，使用玩家碰撞体检查路线；平地连续行走，限制转向速度，绕过墙角与危险地面。
- 检查当前跳跃提升及实际物理参数。跳跃提升 II 且净空充足时，直接跳上两格台阶；效果消失后重新规划。
- 自动行走时疾跑，兼容按住与切换设置。到点、暂停和结束时释放输入；保留原版饥饿限制。
- 箱子与村民交互检查距离和视线；保留实际服务端菜单确认、私人初始物品保护和 `good` 补货确认。

## 安装

下载 `auto-equipment-making-client-1.0.0.jar`，放入独立游戏版本的 `mods` 目录，并移除同模组旧 jar。

依赖：Minecraft 26.2、Java 25、Fabric Loader 0.19.5、Fabric API 0.158.0+26.2、MaLiLib 0.29.3。远程库存集成使用 MiniHUD 0.40.4 和服务器 Servux 0.11.2。

`F6` 设置，`F8` 开始，`F10` 暂停，`F12` 恢复，`F9` 急停，`B` 绑定交付箱。工坊配置和界面设置分开保存。详细使用方法见仓库 README。

## 验证

- 独立单人导航测试：17 个场景全部通过，包括真实信标跳跃提升 II、半砖、低顶、动态障碍、效果消失、切换疾跑和低饥饿值。
- 完整制作回归：6 笔采购，交付 14 件装备、1 盒，消耗 319 级；私人初始物品保持不变。
- 规划内核：9 项测试通过。分发 jar 不含游戏测试；66 个主代码 class 与测试编译输出一致。
- 平地斜线场景从 67 tick 降至 52 tick（减少 22.4%）；不代表整套装备生产提速比例。
- 本次没有验证远程服务器或远程网络握手。完整记录见 `docs/V1_NAVIGATION.md`。
